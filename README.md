# hello-mt

A small, production-shaped DevOps platform on Azure, built for the "Build a DevOps Platform on Azure" capstone. The app is a one-page nginx website; the work is the platform around it: Terraform, Docker, AKS, Kustomize, and GitHub Actions with OIDC.
